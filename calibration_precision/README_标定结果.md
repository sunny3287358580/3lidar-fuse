# 三雷达外参精调结果

日期：2026-10-19（Asia/Shanghai）

## 结果与方向

以中间雷达坐标系为固定参考，单位米。使用列向量：`p_center = T_center_from_sensor @ [x, y, z, 1]`。
`redme.txt` 第一组为左→中，第二组为右→中。左右分别独立优化六自由度；两组采集共享同一套固定外参。未使用左↔右匹配，也未强制角度对称或矩阵互逆。

最终采用完整分辨率、协方差 GICP + 双精度 LM（8cm 最近邻门限），这是本次已测试方案中联合评估得分最好的候选，并非具有外部真值保证的全局最优标定。

## 精调方法

1. 每组采集分别用标准 PCL 1.14 GICP 逐级拟合，8/4/2/1 cm 体素，最后使用全部原始点。
2. 由两组 GICP 结果求旋转均值与平移均值，作为联合优化初值。两组场景不混成一帧，只共享外参。
3. 测试鲁棒 GICP、多初值、完整点云 GICP、6cm/8cm门限、95%截尾等候选。LM内层固定匹配和协方差，外层更新最近邻和协方差。
4. 用统一评估区域比较候选：初始外参下25cm内的固定重叠区域，2cm体素，双向最近邻；距离在10cm处截断。双向及两组采集等权平均。
5. 最终候选分别在2-1、2-2单独重估，检查跨组结果的一致性。

## 误差比较

数值是相同固定区域上的双向点到平面截断RMSE，单位mm；不是外参平移精度，也不是全部点云平均误差。

| 雷达 | 数据 | 初始 | 精调 |

| left | 2-2 | 42.78 | 34.91 |

| left | 3.95 | 0.0753 |

这是在联合解附近分别进行单组优化得到的一致性，不能代替标定板、测量仪器或独立场景真值。两帧场景本身很相似，不能充分验证对新场景的泛化。右侧原始角度需要约6.42°修正，因此应重点查看重叠物体边缘。

## 文件

- `T_center_from_left.txt` / `T_center_from_right.txt`：最终外参。
- `T_left_from_center.txt` / `T_right_from_center.txt`：逆变换。
- `extrinsics_refined.txt`：两组矩阵汇总。
- `extrinsics.json`：机器可读参数。
- `final_report.json`：最终候选、评估与完整分辨率单组验证。
- `metrics.csv`：统一评估区域的精调前后指标。
- `precision_report.json`：候选与优化日志，最终选择须与final_report一致。
- `2-1/`、`2-2/`：初始融合、精调融合、左中右分别变换后的PCD。
- `alignment_comparison.png`：相同范围的投影对比。

## 限制

点云的采样间距、噪声、遮挡、动态物体和雷达内部系统误差会留下厘米级残差；延长迭代不会自动获得毫米级物理精度。LM最近邻可能在极小步长处形成周期；报告将迭代上限和小步长收敛分别记录，不将达到上限称为已收敛。输出小数位用于复算，不代表真实精度。
